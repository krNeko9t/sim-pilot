# 01: 固体形变候选与动态演示

Type: research
Status: ready-for-agent
Blocked by: None (can start immediately)

**依据：**执行时遵循[探索规格](../spec.md)中的参数分类、证据要求与阶段边界。

**What to build:** 让用户通过候选列表和动态视频，审阅玻璃、金属、塑料、果冻、肉、水果，以及家具、玩具、枕头等相关物件的固体形变方案，了解哪些场景适合展示 E、ν 的影响，并获得 AI 初步推荐。

- [ ] 搜索相关最新论文及有价值的既有项目，记录原始来源、发表或项目时间；按上述材料与物件说明覆盖情况及尚待找到合适候选的类别。
- [ ] 为重点候选提供动态演示入口和观看说明，指出视频中的物件、作用条件及值得观察的运动或形变。同类其他候选保留在列表中。
- [ ] 每个候选分别标注参数控制方式和演示证据，说明 E、ν、ρ 中哪些有已知控制能力；引用作者资料、官方文档或代码依据，并区分待核实项与 AI 推断。
- [ ] 对已有参数对比记录实际取值或倍率及固定条件；对效果待复跑的候选，说明可尝试的展示场景。其他可调输入遵循默认值约定。
- [ ] 记录代码、现成示例数据、商业仿真软件依赖和渲染配套的已知状态，作为复跑可行性的初步信息。
- [ ] 给出本类别的 AI 推荐及理由，优先说明视觉合理性与参数影响的可辨识程度；理论或参考对照的价值另行标注。交付供人工审阅的候选资料，复跑在用户选择后进入。
