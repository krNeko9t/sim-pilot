# 04: 黏性流体候选与动态演示

Type: research
Status: ready-for-agent
Blocked by: None (can start immediately)

**依据：**执行时遵循[探索规格](../spec.md)中的参数分类、证据要求与阶段边界。

**What to build:** 让用户以蜂蜜等流体为对象观看候选动态演示，理解目标物理量与黏度等附加输入各自的控制方式，并获得适合展示和后续复跑的项目推荐。

- [ ] 搜索相关最新论文及有价值的既有项目，记录原始来源、发表或项目时间；以蜂蜜等黏性流体为重点说明覆盖情况。
- [ ] 为重点候选提供动态演示入口和观看说明，保留同类其他候选，说明视频实际展示的流动效果和场景条件。
- [ ] 每个候选分别标注参数控制方式和演示证据；按来源说明 E、ν、ρ 中哪些适用于该候选且可调，并将黏度等附加输入单独说明。
- [ ] 对已有对比注明实际改变的参数、取值及固定条件；对相关控制能力尚待复跑的候选，标注推断依据与拟观察的效果。其余可调输入沿用默认值约定。
- [ ] 记录代码、现成示例数据、商业仿真软件依赖和渲染配套的已知状态；参数能力说明引用作者资料、官方文档或代码。
- [ ] 给出本类别的 AI 推荐及理由，优先说明视觉合理性及目标物理量的展示价值，明确仅供视觉参考和可进一步核实调参效果的候选。
