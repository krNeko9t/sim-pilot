# 06: 候选总览与按场景推荐

Type: task
Status: ready-for-agent
Blocked by: 01, 02, 03, 04, 05

**依据：**执行时遵循[探索规格](../spec.md)；输入为 01 固体形变、02 布料薄壳与植物物件、03 颗粒材料、04 黏性流体、05 密度展示场景的候选资料。

**What to build:** 让用户通过统一的候选总览和动态视频入口，比较各材料与展示场景的方案，理解 AI 推荐依据，并选出下一阶段要复跑的候选与场景组合。

- [ ] 汇总 01–05 的候选，合并重复项目，同时保留其各场景、目标物理量和原始来源的区别；同类备选继续可查阅。
- [ ] 提供按材料或现象组织的统一动态演示入口，突出有代表性、有差异的演示，保留各候选的观看说明。
- [ ] 统一列出参数控制方式、适用目标物理量、演示证据，以及代码、示例数据和渲染条件的已知状态；已核实信息、待核实项和 AI 推断分别表述。
- [ ] 对照规格中的物件、材料及 E、ν、ρ 展示目标说明覆盖情况，标记尚待找到合适候选或补充证据的部分。
- [ ] 给出按场景组合的 AI 推荐及理由，允许采用不同仿真方案；优先依据视觉合理性与参数影响的可辨识程度，并标明各推荐依赖的证据。
- [ ] 将结果交付用户审阅选择。交接说明明确：复跑工单按用户选中的候选与场景建立，再搜索工单由实际反馈触发。
