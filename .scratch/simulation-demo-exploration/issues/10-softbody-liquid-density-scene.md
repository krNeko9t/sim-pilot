# 10: 软体入液的密度差异展示

Type: grilling
Status: open
Blocked by: 05

## Question

用户设想的“常规 MPM／FEM 软体扔进液体”应收束成什么具体展示场景，使只改变软体密度时，入液后的浮沉、推移、摆动和形变既丰富又容易比较？据此需要怎样的软体与流体双向耦合能力？

依据[密度场景用户反馈](05-density-demonstration-candidates.md#comments)、[候选总览](../research/06-candidate-overview-and-recommendations.md)与[探索规格](../spec.md)。本票为人工对话决策，使用 grilling 与 domain-modeling。

沿用已明确的意图：密度为主要比较变量，同时保留形变、接触和流体响应。逐项与用户确定物件形状及材料模型、尺度、软体与液体的相对密度组、液体及容器、入液初态、固定的 E／ν 和附加参数，以及最希望观看的互动。

已有资料支持刚球浮沉与多流体密度对照；软体入液的具体 solver 与现成资产仍需匹配。可复用 SPlisHSPlasH、Newton 及其他耦合线索，但应以可变形体与液体的双向响应为实际条件。入液前相同初态的自由落体遵循已记录的物理条件，比较重点放在入液后。

完成时记录用户选择的场景与观察量，并把由此明确的实现／资产问题交给后续研究票，或在候选已确定时建立复跑票。当前票不代用户选择新的效果方向。
