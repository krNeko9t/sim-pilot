# 02: 布料、薄壳与植物物件候选与动态演示

Type: research
Status: ready-for-agent
Blocked by: None (can start immediately)

**依据：**执行时遵循[探索规格](../spec.md)中的参数分类、证据要求与阶段边界。

**What to build:** 让用户观看布料、帽子、塑料瓶、花束、盆栽等对象的动态演示，了解对应项目可调参数、默认附加输入与适用场景，并据此选择感兴趣的方案。

- [ ] 搜索相关最新论文及有价值的既有项目，记录原始来源、发表或项目时间；说明上述对象的覆盖情况及尚待找到合适候选的类别。
- [ ] 为重点候选提供动态演示入口和观看说明，保留同类其他候选，说明各演示实际覆盖的物件或组成部分。
- [ ] 每个候选分别标注参数控制方式和演示证据，说明其与 E、ν、ρ 的对应关系及来源依据；已核实信息、待核实项和 AI 推断分别表述。
- [ ] 记录影响场景的附加输入及已知默认设置，例如厚度或弯曲调节项；说明已有参数对比的取值和固定条件，或提出效果待复跑的展示场景。
- [ ] 记录代码、现成示例数据、商业仿真软件依赖和渲染配套的已知状态；需要另接渲染的候选继续按仿真价值评估。
- [ ] 给出本类别的 AI 推荐及理由，优先说明肉眼可见的参数影响和视觉合理性；明确各候选擅长的场景，供用户选择后复跑。
