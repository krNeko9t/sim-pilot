# 03: 颗粒材料候选与动态演示

Type: research
Status: ready-for-agent
Blocked by: None (can start immediately)

**依据：**执行时遵循[探索规格](../spec.md)中的参数分类、证据要求与阶段边界。

**What to build:** 让用户观看雪、沙堆等颗粒材料的动态演示，明确候选调节项与目标物理量的关系，并获得适合进一步尝试的场景和项目推荐。

- [ ] 搜索相关最新论文及有价值的既有项目，记录原始来源、发表或项目时间；分别说明雪与沙堆的候选覆盖情况。
- [ ] 为重点候选提供动态演示入口和观看说明，指出值得观察的运动或形变，保留同类其他候选。
- [ ] 每个候选分别标注参数控制方式和演示证据，依据作者资料、官方文档或代码说明 E、ν、ρ 的适用含义及调节能力；待核实项和 AI 推断明确列出。
- [ ] 列出已知附加输入及默认设置，说明已有参数对比的取值与固定条件，或提出效果待复跑的场景；区分目标物理量变化与其他调节项变化的证据。
- [ ] 记录代码、现成示例数据、商业仿真软件依赖和渲染配套的已知状态，作为后续复跑判断的输入。
- [ ] 给出本类别的 AI 推荐及理由，说明视觉合理性、可辨识的参数影响和当前证据局限，交付用户可独立审阅的候选资料。
