# 05: 密度影响的展示场景与候选

Type: research
Status: ready-for-agent
Blocked by: None (can start immediately)

**依据：**执行时遵循[探索规格](../spec.md)中的参数分类、证据要求与阶段边界。

**What to build:** 让用户审阅专门展示密度 ρ 影响的场景与项目，通过动态视频和控制条件说明，选择肉眼直观或具有明确理论参照的密度演示方案。

- [ ] 搜索相关最新论文及有价值的既有项目，涵盖有依据支持密度展示的场景；记录原始来源、发表或项目时间，可复用其他类别的项目而独立完成本单交付。
- [ ] 为重点候选提供动态演示入口与观看说明，标明视频实际展示的运动，以及密度参数对比是否已经出现在视频中。
- [ ] 每个候选分别标注参数控制方式和演示证据；核实 ρ 的控制含义与来源，区分代码支持调参、视频已有对比和仅有效果参考。
- [ ] 说明参数对比中的几何、作用条件及其余材料设置；对已有对比记录密度取值或倍率，对待复跑场景说明预期效果的依据与待确认部分。
- [ ] 记录代码、现成示例数据、商业仿真软件依赖和渲染配套的已知状态；能力判断引用作者资料、官方文档或代码，理论判断附原始依据。
- [ ] 分别标注肉眼直观与理论参照的展示价值，给出密度场景的 AI 推荐及理由，供用户选择后复跑。
