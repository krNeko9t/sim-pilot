# 仿真方案探索与参数影响演示

Status: ready-for-agent
Updated: 2026-11-01

共识来源：任务说明、grilling 的 Q1–Q6 回答及 2026-10-30 的用户观看反馈。01–05 已完成首轮候选研究，本轮人工审阅已收束，[候选总览与按场景推荐](research/06-candidate-overview-and-recommendations.md)已交付；已明确的补充问题由独立工单承接，复跑阶段在用户选择候选与场景后进入。术语见 [GLOSSARY.md](../../GLOSSARY.md)。

## Problem Statement

上游将提供几何数据及杨氏模量 E、泊松比 ν、密度 ρ。用户负责正向仿真与视频输出；团队计划将视频交给下游生成模型等方法评分，以判断输入物理属性的正确性或合理性。2026-11-01 用户明确：本轮围绕仿真和视频提出方案，评分方法的设计与有效性评估由下游承担。

工作主体是利用已有几何和材料参数完成正向仿真，按需配套后渲染。候选的主要价值在于能提供何种可用仿真实现与展示场景；论文的研究贡献、外观建模和材料预测／反演分别说明其对当前任务的作用。

当前需要找到适合这项工作的仿真方案，跑出可供团队观看的结果。优先寻找能让物理量变化产生直观差异的场景：合理取值看起来符合现实，明显偏离的取值容易被肉眼识别。通过参考资料或物理量理论定义进行判断的案例也纳入探索。

本次处于探索阶段，以已有项目、论文演示和可复跑示例为起点。

2026-11-01 补充：固体方向的重点是寻找能较广覆盖**完整物体**的正向仿真路线，并理解其运动／形变质量与适用边界。当前以各仿真器自带资产及成熟公开场景为依据，数据格式、建模条件、材料表示和后渲染准备由研究查明；上游输入粒度与对接细节留到后续。现成小例子可作为能力证据，推荐依据还应包含较丰富物体场景的可信效果和迁移范围。用户关心直接使用数字资产配合 PBR 渲染的质量，外观与物理运动分别评价。

## Solution

按以下顺序推进，允许不同场景采用不同仿真方案。

1. **广搜与展示**：尽可能搜集相关项目和最新图形学论文，同时保留有价值的既有项目。按材料或现象整理候选，提供动态演示视频，并给出 AI 的初步推荐及依据。同类项目保留候选列表，重点展开有代表性、有差异的演示。
2. **人工选择与复跑**：用户先审阅视频和候选。随后核实所选方案能否利用公开代码、现成示例数据快速复跑，形成复跑原型和结果视频。复跑方案排除依赖商业仿真软件的方案。
3. **反馈与再搜索**：若结果未达到用户偏好，根据其对材料、运动效果和演示方式的反馈调整搜索，再交由用户选择。

搜索覆盖两组对象：

- **具体物件**：家具、玩具、枕头、塑料瓶、帽子、花束、盆栽。
- **具名材料**：玻璃、金属、塑料；颗粒材料，如雪、沙堆；流体，如蜂蜜；食物，如果冻、肉、水果；布料等。

这些对象共同构成探索范围，最终演示可由多个项目和多个场景组成。

## User Stories

1. 作为仿真负责人，我希望看到覆盖上述物件与材料的候选，以便了解可选方案。
2. 作为仿真负责人，我希望同时了解最新论文和有价值的既有项目，以便依据效果与可用性选择。
3. 作为审阅者，我希望直接观看候选的动态演示，以便判断运动是否直观、符合现实。
4. 作为审阅者，我希望看到 AI 的推荐理由和适用场景，以便安排观看与尝试顺序。
5. 作为审阅者，我希望明确区分直接输入物理量、公式换算和视觉调节，以便理解候选的参数含义。
6. 作为审阅者，我希望分清已有参数对比视频、代码调参能力和单纯效果参考，以便判断现有证据的强弱。
7. 作为仿真负责人，我希望其余可调输入沿用默认值，以便集中观察目标物理量变化。
8. 作为仿真负责人，我希望先用明显偏离的参数取值比较，以便快速找到肉眼可辨识的效果。
9. 作为仿真负责人，我希望按参数选择合适场景，以便分别展示 E、ν、ρ 的影响。
10. 作为仿真负责人，我希望同时考虑日常互动与受控实验场景，以便找到容易看懂的展示方式。
11. 作为仿真负责人，我希望各场景能选择不同仿真方案，以便利用候选各自擅长的效果。
12. 作为仿真负责人，我希望先审阅候选，再核实代码与示例数据并复跑，以便把执行投入用在感兴趣的方案上。
13. 作为仿真负责人，我希望利用离线计算和可用 GPU 资源，以便生成供团队展示的结果。
14. 作为仿真负责人，我希望可使用配套渲染或单独接入 Blender，以便保留仿真效果合适的候选。
15. 作为团队成员，我希望观看所选方案的结果视频，以便讨论输入物理量的合理性。
16. 作为审阅者，我希望将观看和复跑反馈用于下一轮搜索，以便逐步找到满意的方案。

## Implementation Decisions

本节记录探索与演示的执行决定。

### 2026-11-01：完整物体覆盖与质量证据

用户指出，“固体方向为重点”意在覆盖多数完整物体，前轮将推荐过早收窄到少数易复跑示例。固体选型继续研究以下问题，再形成路线推荐：

- 求解器自带／公开场景覆盖哪些完整物体、材料结构和相互作用，扩展到其他物体需要何种建模工作。
- 运动与形变质量的证据是什么；本构、离散、时间步、迭代收敛和接触的近似分别影响什么。
- 外观资产、仿真表示和后渲染如何配合；优先比较已有数字资产与 PBR 的路径，明确降阶或外观表征造成的质量边界。
- 维护与采用仍是选型依据，现成示例和材料字段用于支撑判断；广覆盖能力与质量结论应有对应证据。

本阶段由研究说明各项目示例的数据格式和准备条件；继续使用项目现成数据开展比较，暂不向用户要求上游数据细节。允许不同材料或作用采用不同方案，统一平台和上下游接口仍沿用原范围边界。

### 围绕正向仿真筛选候选

用户补充指出，首轮资料混合了工程项目、数值效率、接触／多相耦合、新物理现象及神经渲染／神经场建模等不同研究目的。后续对重点候选简述**论文或项目的贡献、实际仿真实现、对当前任务的用途**。一项工作可以同时承担多种角色；具体归类按作者资料与实现核实，用户观察作为筛选线索。

| 主要贡献或角色 | 对本任务的取舍依据 |
| --- | --- |
| 工程项目／仿真框架 | 优先考察已有场景、材料参数控制、结果输出、持续维护与实际采用。 |
| 数值效率／稳定性 | 关注其对目标场景规模、材料范围和运行成本的实际帮助；投入随需要收窄。 |
| 接触／多相耦合 | 依据目标物件的互动需求判断价值，核实实现能否用于所需材料和场景。 |
| 新物理现象或材料行为 | 目标效果需要该现象时展开，说明新增模型和参数对当前输入的要求。 |
| 神经渲染／外观场建模、材料预测／反演 | 默认作为实际仿真实现的追溯入口或配套工具线索；进入主要候选时说明可复用的正向仿真能力或具体后渲染用途。 |

神经方法若直接提供适用的正向求解能力，同样按仿真价值评估。候选按实际求解实现关联，保留本构、接触、耦合及示例的实质区别；MPM、FEM 等方法名称或 Warp 等依赖名称用于说明技术关系，复跑仍需定位具体实现与示例。已有参数控制方式和演示证据分类继续适用。

### 2026-10-30 首轮人工审阅后的优先级

具体候选评价见 [01–05 工单的 Comments](map.md)。后续汇总采用这轮用户反馈，首轮研究保留为来源记录。

- 01 固体形变为后续重点；成熟组织和知名研究组作为搜索入口，重视具体项目的持续维护、实际采用及后续发展证据。用户明确感兴趣的候选继续保留，视觉兴趣与维护情况分别记录。
- 02 后续将布料与植物分别建研究工单，塑料瓶单列覆盖情况；主候选排除老论文，关注目前在用和维护的实现。IPC 接触方法、材料模型、框架，以及植物候选的预测／反演、正向仿真、外观表示分别说明。
- 03、04 减少论文逐项展开，集中关注近期、用户多、知名度高的代表方案；04 优先关注 Mixed MPM / Newton、Blender / Mantaflow。
- 05 关注在丰富互动中体现密度差异的场景。软体入液为用户提出的场景线索，另建工单展开；参数对比可固定其他设置，同时保留形变、接触和流体响应。


### 参数控制方式与演示证据分别标注

以下三种参数控制方式都可以纳入候选，明确列出区别：

| 参数控制方式 | 候选中需要说明的内容 |
| --- | --- |
| 直接输入物理量 | 哪些目标物理量可直接输入，以及可核实的单位和适用条件。 |
| 公式换算 | 目标物理量如何转换为项目实际输入，注明已找到的换算依据。 |
| 视觉调节 | 项目提供的软硬程度等调节项，以及与 E、ν、ρ 的对应关系是否已有依据。 |

另按现有演示证据区分：

| 演示证据 | 当前已知内容 |
| --- | --- |
| 视频已展示参数对比 | 现有动态视频中可观察参数变化及其效果；记录视频实际比较的量。 |
| 代码支持调参，效果待复跑 | 代码中有相关参数控制能力，目标效果留到所选候选的复跑阶段确认。 |
| 仅有视觉效果参考 | 现有资料支持观看效果，目标物理量的控制与对比依据待查。 |

两项分类独立记录。艺术化调节产生的效果也可供选择，其物理量对应关系按已有证据表述。

### 参数与场景

- 关注 E、ν 变化是否影响效果；ρ 保留为独立展示目标。每个候选标注其支持和适合展示的目标物理量。
- 其他可调输入采用项目默认值，并在参数对比中保持固定。项目必填项若缺少默认值，在复跑判断中说明所缺内容。
- 接受明显偏离的参数对比。例如 E 可比较参考值的 0.1 倍、1 倍、10 倍；该组数值是示例，具体取值按候选模型适用范围确定。
- 参数对比注明实际取值或倍率。ν 按适用模型的取值范围选择。
- 日常直观场景优先；夹持拉伸、挤压、施加已知外力等受控场景同样可以进入主推荐。
- 各参数可以采用不同场景，尤其是密度。场景之间可以采用不同仿真方案。
- 两类展示价值分别记录：肉眼可判断的视觉合理性；可通过参考或理论定义判断的效果。当前优先前者，单个候选可以只具备其中一类。

### 计算、示例与渲染

- 仿真采用离线计算。其他机器可提供 A800 服务器或 4090 消费级显卡资源。
- 复跑优先使用项目现成示例数据，具体运行环境随所选项目核实。
- 配套渲染是优势；也可手动对接 Blender 渲染。渲染需要另接的候选继续按仿真价值评估。
- 第一阶段可保留仅有论文或演示的候选，明确其代码、示例数据和复跑条件的已知状态。

### 第一阶段交付内容

候选记录包括名称、项目或论文原始来源、材料或场景、动态演示入口、参数控制方式、适用目标物理量、演示证据、代码与示例数据的已知状态，以及 AI 推荐理由。

动态视频是人工审阅的主要入口。参数能力优先依据作者资料、官方文档或代码说明；AI 推断与已核实信息分开表述。首轮的复跑可行性记录属于初步判断，实际复跑核实放在用户选择之后。

## Testing Decisions

本阶段按交付物和外部可观察效果进行检查：

- **候选整理**：对照上述物件、材料与参数展示目标检查搜索覆盖，记录尚待找到合适候选的类别；视频入口指向动态演示，并说明参数能力与证据类别。
- **人工审阅**：用户通过视频与候选说明表达偏好、选择复跑对象；AI 推荐附上可核查的依据。
- **所选方案复跑**：确认代码和现成示例能在选定环境执行，并生成可观看的结果视频；观察目标参数变化是否产生预期展示价值，记录取值、默认设置及实际效果。
- **反馈收束**：以用户对结果的评价决定保留方案或重新搜索。

当前仓库仅有代理工作约定，后续检查随选中的项目和示例确定。

## Out of Scope

- 上下游对接、几何或物理量的数据交换接口。
- 软件工程架构、模块接口、测试 seam、生产化集成及统一仿真平台设计。
- 要求单一项目同时覆盖全部物件、材料和参数。
- 本阶段对真实物件进行独立材料标定；团队使用仿真结果开展其正确性或合理性判断。
- 下游视频评分模型的设计，以及用该评分判断物理属性的有效性评估。
- 在用户选择候选之前开展安装与复跑。
- 将细微参数误差的可辨识性作为首轮硬要求。

## Further Notes

Q1 接受三种参数控制方式并要求明确区别；Q2 其他可调输入使用默认值；Q3 接受明显偏离的参数对比；Q4 接受受控场景；Q5 接受按场景使用不同方案；Q6 接受将尚缺参数对比视频的候选纳入，并区分证据。

交接起点：按本规格开展第一阶段搜索和动态演示整理。具体项目选择、安装方案与运行条件在后续阶段根据证据和用户反馈确定。
